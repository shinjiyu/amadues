# Task: Playable Tetris with Three.js

Working directory is a minimal Vite + Three.js scaffold (`package.json`, `index.html`, `src/main.js`).

## Requirements
- Classic Tetris playable in the browser (board, 7 pieces, rotate, drop, line clear, score, restart)
- Use Three.js (or Canvas2D via three orthographic) — keep deps minimal; `npm install` / `npm run dev` ok
- Single-page game; document controls in a short README comment at top of main entry

## Done when
`npm run build` succeeds and the game is playable via `npm run preview` or `npm run dev`.
