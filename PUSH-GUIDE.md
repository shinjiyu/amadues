## How to Push

### Option A: Use the Handover Script (Recommended)

1. Open a **real terminal** (not the sandbox)
2. Navigate to the repository root:
   ```
   cd D:\kuroneko
   ```
3. Run the script:
   ```
   HANDOVER-PUSH.bat
   ```
4. The script will:
   - Verify you are on `main`
   - Show the ahead count and commit list
   - Ask for confirmation (type `YES`)
   - Pull latest from origin (rebase)
   - Push to `origin/main`
5. After the script completes, verify:
   ```
   git rev-list --count origin/main..HEAD
   ```
   Expected output: `0`

### Option B: Manual Commands

```bat
cd /d D:\kuroneko
git checkout main
git pull --rebase origin main
git push origin main
```

### Post-Push Verification

```bat
git log --oneline -3
git rev-list --count origin/main..HEAD
git remote show origin
```

The ahead count should be **0** after a successful push.
