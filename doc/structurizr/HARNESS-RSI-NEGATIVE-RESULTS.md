# Harness-RSI 否定性结论（推导链与被收回的命题）

> **English:** The derivation record behind two conclusions: (1) the harness loop should **not** be the locus of RSI — self-rewrite adds no reachability and its correctness cannot be affordably certified; (2) the locus is the **tool layer**, because tools are deterministic and verifiable one-by-one. This doc also records every claim that was **retracted** along the way; that list is the main evidence that the chain is load-bearing rather than rhetorical.

> **状态**：2026-09-17 论证记录 · **无实现面**（本篇不定义模块，只定义为什么某些东西不该被实现）

## 1. 这篇是什么

两条结论：

1. **harness agent loop 不需要 RSI**
2. **需要 RSI 进化的是工具本身**

它们不是正向设计出来的，是**一串排除法**的余数：每一步否掉一个候选，最后只剩「冻结内核 + 工具层压缩」一个格子。本篇记录这条链，因为落地文档（[`TOOL-MDL-GROWTH.md`](./TOOL-MDL-GROWTH.md)）只写结论形态，不写为什么别的路都不通——而**已经有人按那些路实现过两次**（HARNESS-RSI P5、dyflow T0），下次还会有。

§5「被推翻或收回的命题」与 §3/§4 同等重要。若只留结论不留收回记录，这套东西会被当成不可证伪的教条。

## 2. 记号

| 记号 | 含义 |
|------|------|
| \(A_{prim}\) | 原语动作集（真正作用于环境的终结符） |
| \(A_{named}\) | 可寻址动作词汇 = 原语 + 已命名工具 |
| \(R\) | harness（策略：交互历史 → 动作） |
| \(C(R,A)\) | R 在工具集 A 下完成任务的期望 token 成本 |
| \(C^*(A)=\inf_R C(R,A)\) | 工具集 A 下的**成本地板**；只依赖 A |
| \(C(K)\) | 知识集 K 的演绎闭包。**幂等**，永不增长 |
| \(R_B(K)\) | 从 K 出发在预算 B 内的可达集。**不幂等**，棘轮全部建立在这一点上 |

## 3. 结论 1：harness loop 不需要 RSI

### N1 自改写不增加可达性

取 plan-act-reflect，令 plan 槽装任意程序文本 \(p\)，act 为通用解释器 \(U(p,\text{obs})\)，reflect 把 \(p'\) 写回 plan 槽。则任何能全量改写自己的 \(R_{full}\)（初始代码 \(c_0\)）被「plan 槽初始化为 \(c_0\)」的 \(R_{par}\) 模拟，每次自改写对应一次 reflect 写入；反向平凡。依据：Kleene 第二递归定理、反射塔可消去性（3-Lisp）。**不可变解释器 + 可变数据能完整吃下自指。**

**但这是模拟不是同构。** \(R_{full}\) 能在动作执行**中途**改控制流，\(R_{par}\) 只能在 reflect 边界改 plan。补上这个差，act 须退化为「执行一条指令」、reflect 退化为「检查这条指令是否写了代码段」——此时同构成立，但 plan-act-reflect 已经变成一台 CPU。故定理的真实内容是：**全量自改写 ≡ 冯·诺依曼架构**；越保留真实结构（plan 是审议、act 是任务级步骤），等价越弱，退化为严格包含。

**同一推论覆盖循环形状**：ReAct + 一个文件读写工具即可模拟 plan-act-reflect（plan 槽 = 一个文件）。反过来，\(A\) 里没有造工具能力的 plan-act-reflect 模拟不了有该能力的 ReAct——因为**循环结构本身从不扩张 \(A\)**。

### N2 性能分解（承重梁）

\[
C(R_t,A_t)-C^*(A_\infty)=\underbrace{\big[C(R_t,A_t)-C^*(A_t)\big]}_{\text{调度层可收：有界}}+\underbrace{\big[C^*(A_t)-C^*(A_\infty)\big]}_{\text{只能靠扩张工具：无界}}
\]

**harness 改进是「收差距」，工具改进是「降地板」。** 此式近乎重言式——实质内容不在定理里，而在「哪一项主导」这个经验问题上（见 §6）。

工具无穷不破坏分解：任一时刻 \(A_t\) 仍有限，harness 能收的仍是到 \(C^*(A_t)\) 的有界差距；\(A_t\) 增长只让第二项持续变大，**结论被加强而非推翻**。

### N3 验证不可行（比 N1/N2 更硬的理由）

| 验证方式 | 结论 |
|---|---|
| **确定性认证** | **不存在**。对任何固定有限测试集，总能构造一个在其上最优、在别处任意差的 harness（极端情况直接硬编码） |
| **概率认证** | 存在但**不可付**。描述长度 ≤ \(B\) 比特的类，Hoeffding + 联合界给出 \(n\ge(B\ln 2+\ln(2/\delta))/(2\varepsilon^2)\)。10KB harness（\(B\approx8\times10^4\)）取 \(\varepsilon=0.1,\delta=0.05\) ⇒ 约 **280 万个任务**；压到 1KB 仍需 28 万 |
| **证明式认证** | 哥德尔机。**瓶颈不是改写范围，是验证方式**：每次改写须在固定公理系统内搜出「此改写提升期望效用」的证明，搜索不可判定，有界版常数无意义 |

⇒ **测试只能否证，不能认证**（Popper 而非 PAC）。一次失败推翻一个 harness，成本 O(1)；任何可行数量的通过都断言不了「几乎全部」。

把「改写范围」与「验证方式」拆成两轴：

| 验证方式 | 只改数据/plan | 改自己的代码 |
|---|---|---|
| 证明 | 可实现但很弱 | 哥德尔机，不可实现 |
| 测试 | 我们在做的 | **可实现，但无保证** |

右下角今天就能跑。它的代价正是上一条：每接受一次改写就累积一份未认证的改动，长程是**不可检测的漂移**（检测需认证，认证不可付）。

### N4 「空间有限」推不出「可高效找最优」

- 有限 horizon POMDP 最优策略：**PSPACE-完全**（Papadimitriou–Tsitsiklis 1987）
- 无限 horizon 最优策略存在性：**不可判定**（Madani–Hanks–Condon）
- 允许任意代码时「此 harness 成本 ≤ k」：**Rice 定理**不可判定

harness 观测任务的部分信息，正是 POMDP。所以空间有限与搜索困难并存。⇒ 不该 RSI harness 的正确理由是：**它只能收有界的差距，因此应「满足即冻结」（satisficing），而非优化。**

### N5 不变量基座

\(R_{par}\) 的不可变循环是**公理基座**，在所有改写下存活；\(R_{full}\) 能改掉自己的 reflect 步，因而**能销毁自己的改进判据**。外延等价，内涵不等价。证明侧的对应物是 Löb 障碍。

**哥德尔机的固定公理系统就是伪装的不可变内核**——Schmidhuber 没有绕开基座，只是把基座放在了证明系统上。故「可全量 rewrite 的 harness」不是更强的架构，它是同一个架构，只是把基座藏起来且不保护不变量。

### N6 判决

冻结内核。规模要小到**人能通读审计**——这是放弃统计认证（N3）之后唯一付得起的那种保证。

## 4. 结论 2：工具才是进化位点

### T1 由 N2 第二项直接得出

工具进化 = 动作空间扩张 = 跳出「固定接口下调度层迅速饱和」的唯一出口。

> 「harness 同构类空间有限」的**严格版是假的**（程序空间可数无穷；只要能放任意代码就谈不上有限）。可辩护的版本是**相对固定动作空间与观测空间**：有限性来自**固定接口**，不来自「它是个 harness」。

### T2 但工具也不扩张能力

被创建的工具是已有原语上的程序，它扩张 \(A_{named}\) 而非 \(A_{prim}\)：闭包里一个原本需 50 步 ReAct 到达的点变成 1 个动作。**这是成本变换，不是能力变换。**

真正的 \(A_{prim}\) 增长只来自**获取**外部接口（装二进制、拿凭据、接新端点）——那不是组合，是移动环境边界，受**权限**约束而非智能约束。落地对应 [`TOOL-MDL-GROWTH.md`](./TOOL-MDL-GROWTH.md) 的 M9/M12。

### T3 验证可行性的不对称（本篇最关键的一步）

工具多数是确定性的，接受判据**逐个可判定**（历史实例重放），不吃 N3 那个统计联合界；内核的正确性只能统计地认证，而认证不可付。

> **该冻结的东西正好是不可认证的，该进化的东西正好不需要统计认证。**

这不是巧合——是同一个描述长度在两边起作用。

### T4 度量取 token 成本，且不引入先验

反对意见「引入评价即引入先验」成立，但 token 成本躲开了它：它不是设计出来的偏好，是**资源事实**。且它有梯度——Collatz 下 \(\mu_0\) 恒为 0 导致 \(\mu_1\) 无定义，token 成本没有这个病，每次运行都出数。

同一批日志换个度量即翻转：43 轮计划 churn 在「是否证完」下全部显示 `lakeOk: true` 完全隐形，在 token 成本下是刺眼的净烧钱。

### T5 「何时造工具」是压缩题，不是判断题

\[
k\,(c_{inline}-c_{tool})\;>\;c_{build}+c_{carry}\cdot S
\]

除复用次数 \(k\) 外全部可从日志量出；\(k\) 用历史频次估（有偏，但那是**测量**不是先验）。候选不由模型「想出来」，是动作日志上的**频繁子序列**一遍离线挖出。

### T6 识别：这就是文法归纳

把频繁子序列抽出、命名、以降低整个轨迹语料的描述长度——`create_tool` 就是**加一条产生式**，工具库就是原语字母表上的一部文法。四个直接后果：

| 后果 | 内容 |
|------|------|
| 目标函数 | **MDL**：库描述长度 + 语料用库表达后的长度。单标量、可计算、无先验 |
| **退役判据自动出现** | 删掉某产生式使总 MDL 下降则退役。同一目标管两头——此前被认为是「没人实现的那一半」 |
| 层级自动出现 | 工具调工具 = 嵌套产生式。但**必须先用当前库重编码日志再挖**，否则深度恒为 1 |
| 复杂度类已知 | 最小文法问题 NP-hard（Charikar et al. 2005）；BPE 式贪心在对数因子内且极便宜 |

模型的职责被压到只剩**反合一 + 写函数体**，不负责决定造不造。

### T7 前置条件（后来被实测加严）

机制**严格是回顾性的**：挖掘只能发现已复发的东西。任务流必须有复发结构——**无复发 ⇒ 无压缩 ⇒ 无增益**，这是前置条件不是待修缺陷。

> P2 实测把这条加严了：不是「观测大」，而是「**中间**观测大」。获取步的观测就是它的价值，任何工具都省不掉。见 [`TOOL-MDL-GROWTH.md`](./TOOL-MDL-GROWTH.md) §9 第四条与 §11.6。

### T8 已知风险有名字

**utility problem**（Minton 1988/1990）：学到的宏因匹配与选择成本反而拖慢系统，对应 \(c_{carry}\) 项。文献既指出了这个洞，也验证了补法（把退役放进同一个 MDL 目标）。

## 5. 被推翻或收回的命题

| 曾主张 | 结局 |
|---|---|
| harness 描述长度小 ⇒ 统计认证便宜 | **收回**。按 N3 公式算出 280 万任务；改为「测试只能否证」 |
| 基数有限性可作为不 RSI 的理由 | **放弃**。\(|A|^{|H_{<T}|}\) 是双指数，对性能界无用。但它对**样本复杂度**有用（进来的是 \(\log N\)）——同一个命题在两处一废一立 |
| 「harness 同构类空间有限」严格版 | **改为条件版**：相对固定动作空间与观测空间 |
| 「何时造工具」落在模型提案分布里、harness 碰不到 | **拉回**。它是压缩题（T5/T6），可机械化 |
| 证明式验证成本不可实现 | **部分推翻**。数学里 Lean + 自动形式化已使其可付（FLT 三公理无 sorry；受迫 NS 形式化 17 小时）。**对 harness 仍成立**——没有「这个 agent 更好」的 Lean |
| 按「同余类 / 重写+SAT / 2-adic」做路线级蒙特卡罗采样 | **撤回**。那是 Collatz 专用先验，而且恰好塞在「先验决定一切」的那个环节（提议分布）上 |
| dyflow `ws_*` 注册 0 次 ⇒ 模型不做这个判断 | **归因修正**。图里任何单节点都看不见跨任务复发——不是不愿判断，是**没有参与者具备做这个判断所需的观测**。⇒ 仍支持离线挖掘，但内联造工具**未被证伪**，须保留对照臂（M11） |
| 把会增长的东西叫「闭包」 | **用词错误**。\(C(K)\) 幂等、永不增长；会长的是 \(R_B(K)\)，它**不幂等**（\(R_B(R_B(K))\supsetneq R_B(K)\)），棘轮全部建立在这个失败的幂等性上。且 \(\bigcup_n R_B^{\,n}(K_0)=C(K_0)\)：永远逃不出，但每个有限时刻都严格在内部 |
| 蒙特卡罗/取消评价即可获得涌现 | **改写**。取消评价不取消先验，只把先验从选择阶段搬到**提议分布**。实证：`lake` 是中立的，把 agent 锁死在同余类拆分上的是 LLM 的提议分布 |

## 7. 落地与后续证伪

结论 1 ⇒ 内核冻结、\(A_{prim}=\{\texttt{shell\_exec}\}\)、元层（工具索引构建）由内核**固定约定**提供而非作为动作暴露。
结论 2 ⇒ 外循环：重编码 → 挖掘 → 反合一 → 重放验收 → MDL 收录/退役。

两者的落地面、不变量（M1–M12）、可证伪信号表在 [`TOOL-MDL-GROWTH.md`](./TOOL-MDL-GROWTH.md)。

> **当前证据状态（P0–P3，真实 LLM）**：详见 [`TOOL-MDL-GROWTH-RESULTS.md`](./TOOL-MDL-GROWTH-RESULTS.md)。
>
> - **M11（对照臂 A）本次未被推翻**：同三种子下 `create_tool` 在 72 任务上调用 0 次；臂 B 有 1/3 种子给出完整正例。
> - **正面命题「每任务成本单调下降」仍未获统计证实**：仅 n=1 结构完整的正例；聚合效应小于批内离散。
> - 这不影响本篇 §3 的否定性结论（它们不依赖压缩机制成立）。§4 从「纯设计」升级为「机制可运行 + 关键对照成立」，但仍**不是**普遍战果。
