| **退役不得惩罚采用成功** | M13：仍被调用时用收录时锁定的节省；§11.15 的退役是误杀 |

## 3. 被证伪或收窄的

| 曾主张 / 隐含假设 | 结局 |
|------------------|------|
| 「每任务成本单调下降」是机制的普遍产出 | **证伪为条件命题**。仅当：中间观测占主导、有可挖复发、工具实际被调用、正确率方差可控。聚合上效应仍小于批内离散 |
| 「观测足够大」⇒ 可压缩 | **收窄**。须是**中间**观测大；获取步再贵也省不掉（schema 族零产出是正确判决，§11.6） |
| 组件测绿 ⇒ 真实 LLM 下成本下降 | **证伪**。组件测替机制假定了「模型会用工具」和「被折叠观测可压缩」——后者被 M12 推翻 |
| 降难度可抬正确率、清掉测量噪声 | **失败**。难度被模型的上下文内组合吸收，不沉淀成工具；正确率还更差（§11.12）。§11.14：降 per-task **单独**即零收录 |
| `obsTokens` = 执行器产出量 | **修正为上下文成本**（截断后）。记错会让 ΔL 荒谬偏负（§11.8） |
| 收录了工具 ⇒ 成本下降归因于机制 | **不够**。须看 `toolCalls`：收录后调用 0–1 次时，曲线变化与机制无关（§11.7） |
| 「观测截断须事先告知」对本机制有利 | **收回默认开**（§11.14）。告知单独就把库打死；正确率未改善。选项保留、默认关 |

## 5. 对否定性专篇的回写

[`HARNESS-RSI-NEGATIVE-RESULTS.md`](./HARNESS-RSI-NEGATIVE-RESULTS.md) §7 曾写：「§4 目前只是设计，不是战果」「最关键的待证伪项是 M11」。

**更新后：**

- M11：**本次未被推翻**（臂 A = 0）。否定性专篇 §4「工具才是进化位点、判断须离线机械」多了一条相对证据。
- §4 落地仍**不是**普遍战果：正面成本下降只有 n=1 结构完整的正例；普遍命题仍欠统计。
- 否定性结论（harness 不需要 RSI）**不依赖**压缩机制成立——本篇 §3 的收窄不回溯削弱 N1–N6。
