# 开放问题清单（需与朋友 / 业务方确认）

> 评审前建议逐项打勾或补充答案；答案可写在本文件下方或单独会议纪要。

---

## A. 数据与资产

- [ ] **案例数据源**具体是什么？（MySQL / 飞书表 / 本地 Excel / BI 导出？更新频率？）  
- [ ] 案例里是否包含 **可对外引用的效果数字**（ROAS、GMV），还是仅内部相对值？  
- [ ] **目标客户名单**规模？字段有哪些？是否含已合作 / 仅线索？  
- [ ] 是否已有 **CRM**（销售易、纷享销客、自建）？系统要与 CRM 主从关系如何定？  
- [ ] 投放数据来自 **本公司结案**、**客户自述**，还是 **第三方监测**（秒针、AdMaster 等）？

---

## B. ROI 与排序

- [ ] 业务认可的 **ROI 定义**是哪一个？（见 [requirements.md §5](./requirements.md)）  
- [ ] 没有历史投放的新客户，是否接受 **「案例迁移分」** 排序？  
- [ ] 是否存在 **战略客户** 必须置顶（绕过 ROI）？  
- [ ] 排序列表的 **刷新节奏**（日/周/实时）？  
- [ ] 筛选错误的代价：更怕 **漏掉好客户** 还是 **浪费销售精力**？（影响阈值设计）

---

## C. 情报采集与合规

- [ ] 公网信息采集（新闻、招聘、社媒）是否 **法务已批准**？  
- [ ] 客户联系人、手机号等 **个人信息** 是否纳入系统？存储何地？  
- [ ] 是否需要 **境外企业** 数据（GDPR / 跨境传输）？  
- [ ] enrichment 默认 **全自动** 还是 **人工审核后入库**？

---

## D. 方案生成

- [ ] 方案交付物格式：**PPT / Word / PDF / 在线文档**？  
- [ ] 是否有 **品牌方固定模板** 必须遵循？  
- [ ] 策划愿意接受的 AI 介入深度：**仅大纲** vs **全文初稿**？  
- [ ] 方案是否需要 **多语言**（中英）？  
- [ ] 引用案例时是否需要 **脱敏**（隐去原客户名）？

---

## E. 组织与实施

- [ ] 首期用户人数与角色分布？  
- [ ] 预算与时间窗口（PoC / MVP）？  
- [ ] 是否必须 **私有化部署**？能否用国内云 SaaS + 私有化 LLM？  
- [ ] 独立产品 vs 内部工具：**是否需要对外售卖**？  
- [ ] 是否与 Kuroneko 技术栈复用，还是全新仓库？

---

## F. 成功指标（试点）

- [ ] 情报完整率目标？  
- [ ] 排序榜单 **策划/销售认可率** 调研方式？  
- [ ] 单份方案 **节省工时** 如何度量？  
- [ ] 最终业务结果：**拜访率、赢单率、方案中标率** 是否回流系统？

---

## H. 编排平台（新增）

- [ ] 是否已有/可部署 **私有化 Dify**？若无，是否接受 **n8n + 自研 LangGraph 服务**？  
- [ ] 探索 Agent 用 **同步 blocking** 还是 **异步 + Webhook**（影响「调研实况」UI）？  
- [ ] `tools-service` 是否允许访问 **公网搜索 API**（博查/Serper）？  
- [ ] 是否与 Kuroneko **InnerBrain** 统一 Agent 运行时，还是独立 Dify 租户？

## G. AI 零知识启动

- [ ] **公网调研范围**：仅大陆中文？是否含境外站点/社媒？  
- [ ] **审核策略**：冷启动是否 100% 事实需人审后才给销售？  
- [ ] **搜索 + LLM 月预算**上限？（决定每客户 query/抓取次数）  
- [ ] 是否接受产品定位为 **「AI 初研 + 人审定稿」**（非完全无人值守）？  
- [ ] 域名黑名单（竞品监测平台、敏感媒体）是否由法务提供？  
- [ ] 探索时是否允许 AI **主动尝试** 连接内网案例库（只读账号）还是必须等 IT 排期？
