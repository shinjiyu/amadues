# 本机进程总控（local-dashboard）

**English summary:** Optional host-level UI to start/stop dev processes. Integration is machine-specific and **not part of the public Amadues docs**.

公开仓库不包含固定端口、页面 ID 或 sync 脚本路径。

请在本机创建 **`doc/ops/local/notes.md`**（见 [local/README.example.md](./local/README.example.md)）记录：

- local-dashboard 安装目录
- `scripts/sync-local-dashboard.ps1` 用法
- 注册了哪些服务与端口

通用 Agent 启停见 [deploy/agent-quickstart.md](../deploy/agent-quickstart.md) 与 [agent-docker.md](./agent-docker.md)。
