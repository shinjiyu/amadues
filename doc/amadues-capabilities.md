# Amadues 能力介绍

> 一套**可长期运行、断点不丢、越用越强**的自主 Agent 栈。
> 外脑负责策略与对话，内脑（Pi-mono / DyFlow）负责把目标拆成节点并逐个执行；
> 全程以 **File as Context** 持久化——进程重启，任务从原处续跑。

---

## 一句话

给一个目标，Amadues 会自己规划路径、调用工具、踩坑后沉淀经验，并在需要时**派生出更多执行体**协同完成；过程中产出的可复用结论会被蒸馏成技能，下一次直接复用。

---

## 三个代表性战绩

### 1. 零知识攻克番茄网：自主登录 + 连续采集

在**没有预置任何接口文档、字段映射、登录脚本**的前提下，Agent 仅凭一个目标自主摸索：

- 自行探测站点页面与 `/api/author`、`/app/book/*` 等接口，边试边记。
- 把用户粘贴的 Cookie 收进**钥匙串（Keychain）**，按引用注入到 `.brain/secrets/`，既能持续鉴权又不泄露到日志/群聊。
- 登录态、章节序号、PowerShell 中文乱码、ProseMirror 编辑器等坑，全部沉淀为 `避坑.fanqie.*` 约束，后续任务自动规避。

结果：从"零先验"到稳定的**连续登录与采集**，并基于采集到的爆款规律反向产出 120 万字级长篇网文创作提纲。

### 2. 自我复制：把大任务派生成协同执行体

- 内脑遇到复杂目标先 **DECOMPOSE** 成节点图，再为子任务**派生独立的 inner-brain worker 子进程**并行推进。
- 多实例（Gin / Shiro / Kuroneko 等）可分工，研究成果通过 `write_skill` 写入共享技能库，被其他实例**跨 Agent 复用**——一处习得，多处受益。

### 3. 自我优化：越跑越聪明

- **避坑沉淀**：每次失败由 Constraint Governor 归一成 topic 化约束（同类只留最新一条），下轮提示词自动带上。
- **技能蒸馏**：里程碑达成时强制 `write_skill`，把"结论摘要 + 可复用步骤 + 验证"压成可检索条目，存入 drive9。
- **节点提升**：被验证有效的执行流程提升为可复用的 local node，下次同类任务直接套用。
- **机械验票**：节点完成有交付物契约校验（文件/JSON 字段/stdout 标志），杜绝"假完成"。

## 为什么能做到（核心设计）

| 能力 | 机制 |
|------|------|
| 任务不中断 | **File as Context**：状态、记忆、交付物全部落盘，进程重启从原处恢复 |
| 自主执行 | **外脑 / 内脑 双层**：外脑做策略与对话，内脑 DyFlow 做 Designer–Runner 循环 |
| 越用越省 | **技能库 + 避坑库 + 节点提升**：经验蒸馏、跨 Agent 复用 |
| 凭据安全 | **钥匙串**：Cookie / API Key 与 mem9、聊天记录隔离，按引用注入、可轮换、可审计 |
| 架构可治理 | **Structurizr 为架构权威（ADL）**：能力先建模再实现，防止架构漂移 |

---

## 适用场景

- 站点情报采集 / 竞品调研（零知识启动，无需预先配连接器）。
- 长链路内容生产（调研 → 提纲 → 按章生成）。
- 需要长期跑、可断点续、可多实例协作的自动化任务。
